# Regras de negócio — Tilo

Esta pasta contém a documentação técnica oficial de negócio do Tilo: as regras e os fluxos do produto que estão implementados.

O Tilo é uma ferramenta local para o dono de projetos de software: ele escolhe um projeto e trabalha em suas pendências, em sessões do Claude Code e em conversas com o Claude, aprovando na tela os comandos que o Claude quer executar.

## Documentos

- [projetos.md](projetos.md): cadastro, edição e estrutura base dos projetos.
- [pendencias.md](pendencias.md): leitura de `pendencias/README.md`, prioridades, estados e conclusão.
- [conversas-claude.md](conversas-claude.md): conversas do painel, modelos, modo plan, edição e comandos.
- [sessoes-terminal.md](sessoes-terminal.md): sessões do Claude Code no terminal.
- [aprovacao-de-comandos.md](aprovacao-de-comandos.md): o que o Claude pode fazer sozinho, o que pergunta e o que é bloqueado.
- [permissoes-do-projeto.md](permissoes-do-projeto.md): pacotes, comandos lembrados, bloqueios e produção por projeto.
- [documentacao-com-claude.md](documentacao-com-claude.md): montar e atualizar `docs/` com o Claude.
- [biblioteca-de-documentos.md](biblioteca-de-documentos.md): acervo de documentos técnicos reaproveitáveis.
- [consumo-de-tokens.md](consumo-de-tokens.md): tokens por conversa e consumo estimado do dia e da semana.
- [alteracoes.md](alteracoes.md): aba Alterações, o git visual com vínculo à conversa.
- [auditoria.md](auditoria.md): registro das decisões.

Conceitos ainda em aberto ficam em [../../planning/](../../planning/README.md); pendências do dono em [../../pendencias/](../../pendencias/README.md).
